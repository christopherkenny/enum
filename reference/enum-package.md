# enum: Enumerate Partitions of Grid Graphs

Enumerates polyomino tilings of grid graphs. Partitions an m by n grid
into k connected pieces where each piece has a size within given bounds,
under rook or queen contiguity rules. A translation of the Julia
'enumerator' package by Schutzman (2019)
[doi:10.5281/zenodo.3467675](https://doi.org/10.5281/zenodo.3467675) .
